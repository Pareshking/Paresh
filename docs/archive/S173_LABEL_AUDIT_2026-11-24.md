# S173 (b): labels and units against the glossary, page by page (24 Nov 2026)

**Status, 24 Nov 2026:** every open mismatch and lead below is fixed or written into the glossary (owner: "go with your recommendation"); see TODO S173.

Read-only audit of `src/ui` (main at d2c3540) against `docs/GLOSSARY.md`. Nothing on a page was changed:
the owner sees this list first (S173 (c)), and other sessions are editing the views. Line numbers are as of

## How it was done

1. Every string literal under `src/ui` (docstrings and CSS or HTML comments left out) was scanned with the
   glossary's "Not" column written as patterns (`tests/banned_synonyms.json`, 15 rules across entries 1-11).
   170 hits in 94 distinct places (file, rule and the words around the hit).
2. Each hit was read in its code and sorted: an open mismatch a reader sees (owner to decide), an allowed use
   (the glossary's own exceptions), or a data key a page never prints (a column of the ranking frame, a lookup).
3. Labels the patterns cannot catch were looked for by hand: other names for one idea (today's drawdown,
   market cap) and units on gaps ("%" against "pts").

Rows below with an ID in a table are the ones the test's allow list points at; the "Leads" rows are for the
owner and are not in the allow list (no pattern finds them).

## (a) Is the glossary done?

Mostly. S173 (a) asked for a glossary in `PAGE_DESIGN.md`; it was written as `docs/GLOSSARY.md` in S193 item D
(owner-decided, 23 Nov), and `PAGE_DESIGN.md` §3a rule 6 points to it. `scripts/glossary_audit.mjs` reads every
rendered page against it in CI. No second glossary is needed. Three ideas it does not yet settle, all found
below: today's distance below the peak (SH-1), market cap against "market value" (SH-2), and "52W" against
"52-week" (SH-3).

## The guard (S173 (d))

`tests/test_banned_synonyms.py` reads the rules from `tests/banned_synonyms.json` and scans every string literal
in `src/ui`. Today's 94 places are allow-listed there, each with its row above; any further occurrence (a new
label, sentence or key with a banned word) fails with the file, line, words around it, the glossary's word, and
the JSON to add if it is a key. A negative control in the same file proves a new "12-month", "Max DD", "Industry"
head, "since inception", "MTD", "50-day average", "crore" and "Total Market" each fail and the glossary's words pass.
