# S193 item B, group 3: Sectors and Market sentences against the data (23 Nov 2026, prices of 20 Nov 2026)

## Method

- **Rankings:** the published table for each system, read with `ranking_store.fetch_snapshot` (750, 1,000 and 377 rows, `price_as_of` 2026-11-20, source screener).
- **Prices:**
  - The Screener store, read with `price_source.fetch_screener_store` and `from_screener`. This is the app's `deep_adj_close`, the frame both pages read: `app.py:597-600` takes `chosen.close[keep]` with no NSE fill.
  - NSE's daily long file, `data_cache/nse_long_close.parquet`. It is a second, independent and fully daily source, and covers the 750, the 1000 and 315 of the 377 Nano stocks.
- **Index closes:**
  - `data/nse_total_market.csv` (Nifty Total Market).
  - `data/benchmarks.csv` (Nifty 500 and Nifty 50).
  - `data/benchmark_indices.csv` (the size indices).
  - `data/nse_indices_history.parquet` (NSE's sector indices). Only the list of the 37 keys in the "Sector" family came from `indices_page.every_index`.
- **Members of each date:** `membership.load_history` / `members_on`.
- **Recomputation:** every figure was computed again in pandas (equal-weighted levels, leads, EMA shares, net new highs, month runs, 10-month and EMA gaps, index returns), in scripts in `scratchpad/g3/`: `recompute.py`, `shares.py`, `ex.py`, `nnh.py`, `indices.py` and `pit.py`.
- **Rule for numbers:** "TRUE" means the recomputed value rounds to the number shown. Where the two price sources disagree, both values are given.

## Also found (not in the input list)

- **Root cause of the three FALSE Nano chart heads.** `@st.cache_data` on `_chart_series(_key, _prices, _bench, pit)` (`market_questions_view.py:310-311`) hashes only `pit`.
