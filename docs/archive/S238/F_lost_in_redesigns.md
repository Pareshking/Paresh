# F. What the pages used to show and no longer show (read-only inventory, 28 Nov 2026)

Owner, 28 Nov 2026: "Last time redesigning time also lots of information and sections we lost which was really useful for insights."

**Method.** (1) A script walked all 413 commits that touch `src/ui/` or `app.py` (15 Sep to 28 Nov 2026). For each one it pulled every
heading-like string (card titles, `<h1-4>`, kickers, `st.subheader`/`expander`/`tabs`, nav anchors, chart titles). It then listed the strings
missing at HEAD, each with the commit after which it was last seen: 129 hits, mostly renames. (2) By hand, page by page, the code before each
November redesign was compared with HEAD's: the old Dashboard (`c07710e2^`), Portfolio (`f4152a80^`), Actions (`942e0976^`), Screener
(`8ac2eda6^`), Market/Breadth (`487a230e^`), Sectors and Backtest (`38ce0dba^`), Stock (`4098c5bf^`), Indices (`1311f248^`), and Watchlist, Guide
and Configuration on 15 Nov. (3) `CHANGELOG.md` was searched for "removed / gone / dropped / left out". (4) Every candidate was checked against
`docs/*_REQUIREMENTS.md`, `docs/TODO.md`, `docs/HANDOVER.md`, `docs/archive/*` and the commit text for the owner's own words about that item.

**Rule used (coordinator, 28 Nov).** A removal counts as owner-decided only when there is a quote of the owner approving that item. "Approved
mock-up" or "approved redesign" is a general approval. Those rows are marked **"redesign approved, item not named"**: the owner approved what he
saw, not what was left out.

**Not checked:** the live site (nothing was run); mock-up artifacts (not readable here); conversation text that never reached the repo; pages
before 15 Sep 2026. Every heading-level change is covered. A figure inside a section that was dropped without its heading changing would only
have been found if the CHANGELOG mentions it or it showed in the hand comparison. Anything marked (inferred) was worked out, not quoted.

Counts: **Table 1, 13 items with no owner decision for the item** (10 of them "redesign approved, item not named"). **Table 2, 20 owner-decided
removals.** **Table 3, 14 items that moved and are not lost.**
