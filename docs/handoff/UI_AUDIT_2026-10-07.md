# UI audit: repeated text and look-alike blocks built twice

_Read-only audit, 7 Oct 2026, code at `fd2a87d` (branch `perf/long-build-actions-pack`). Nothing was changed._

**How it was done.** I read every view in `src/ui/views/*.py`, plus `page_kit.py`, `components.py`, `charts.py`, the `render_saas_table` part of `theme.py`, and the page functions in `app.py`. I grepped `tests/` and `scripts/*qa*.py` for each string and class that would change.

**What was not checked.** I did not open the live site (https://paresh.streamlit.app), so I cannot say what is above the fold at a given width. Line numbers are from the code above. The order of blocks on screen comes from the order of the calls.

**Rule used** (WP8 in `docs/UI_OVERHAUL_PLAN.md`): a figure appears once per page, and a caption stays only if it changes a decision.

## 0. The owner's two Actions examples, answered first

| Example | Finding |
|---|---|
| Subtitle "Next rebalance if prices hold. Checked 30 Oct close, fills 2 Nov." vs the tile "Next rebalance · Fri 30 Oct · 18 sessions away · fills Mon 2 Nov" | **Confirmed duplicate.** Both are built from the same `check`/`fill` values: subtitle at `actions_view.py:238`, tile at `actions_view.py:285-286`. The tile says more (weekday, sessions away), so keep the tile and cut the subtitle (see A1). |
| "Where they come from" vs "Industry exposure" | **Same renderer, different shaping.** Both call `kit.bar_list`. Qualified: `qualified_view.py:126-132`, rows from `industry_rows()` at `:54-64`. Portfolio: `portfolio_view.py:632-640`, an inline `groupby`. They look different because the rows are built differently. **Qualified**: rows are counts; top 6 plus an "N others" row; the label is the bare industry; the value reads "5 · 17%"; aside "by industry"; a concentration caption under it. **Portfolio**: rows are weights; every industry is listed; the label reads "Industry (3)"; the value reads "14.2%"; no aside. The suspicion of separate code is right for the **row building**, not for the drawing. Fix: one row builder `kit.breakdown(...)` with the Portfolio format as the default (family C2). Note: "Where they come from" is on Actions only as the embedded qualified list inside the "Buy candidates" expander (`actions_view.py:338-339`). Actions has no "Industry exposure" card; that one is on Portfolio. |
